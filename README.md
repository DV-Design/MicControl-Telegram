# Danygramm для Android

Собрал свою версию Telegram и назвал её Danygramm. Добавил выбор обработки микрофона в личных звонках и перевод входящих сообщений прямо в чате. Для работы в фоне и обновлений есть отдельные настройки.

За основу взял официальные исходники [Telegram для Android](https://github.com/DrKLO/Telegram) 13.0.2 (7175), commit [`f32ffeec763f0bdbf4bec25b52d654f77bff733d`](https://github.com/DrKLO/Telegram/tree/f32ffeec763f0bdbf4bec25b52d654f77bff733d). Danygramm выпускаю как неофициальную сборку.

На основе рабочей 1.2 с картами добавил срез верхних частот около 5 кГц в режиме «Изоляция голоса».
- [Предыдущая тестовая 1.2](https://github.com/DV-Design/MicControl-Telegram/releases/download/danygramm-1.2/Danygramm-arm64.apk) · [Релиз и SHA-256](https://github.com/DV-Design/MicControl-Telegram/releases/tag/danygramm-1.2). В ней подключил карты; работу проверил на телефоне.
- [Стабильная Danygramm 1.0 для arm64](https://github.com/DV-Design/MicControl-Telegram/releases/download/danygramm-1.0/Danygramm-arm64.apk) · [Релиз и SHA-256](https://github.com/DV-Design/MicControl-Telegram/releases/tag/danygramm-1.0).
- [Предыдущая тестовая 1.1](https://github.com/DV-Design/MicControl-Telegram/releases/download/danygramm-1.1/Danygramm-arm64.apk).

В 1.2.1 коэффициент RNNoise оставил 1,60. Голос в изоляции может звучать глуше; обрывы речи на громком фоне могут сохраниться. Интерфейс этой версии не запускал, результат в звонке ещё нужно проверить на телефоне. Если обработка мешает речи, выберите обычное «Шумоподавление».

Автоматическое обновление пока остаётся на стабильной 1.0. Репозиторий публичный, для скачивания вход в GitHub не нужен. Пакет и подпись проверил в готовом APK: обновление можно установить поверх прежнего MicControl/Danygramm, не удаляя приложение и его данные.

## Как пользоваться

В личном аудио- или видеозвонке нажмите «Микрофон» внизу справа. Панель появляется только по нажатию. Можно выбрать изоляцию голоса, обычное шумоподавление или режим «Без эффектов». В последнем выключены подавление шума, RNNoise и автоматическое усиление; эхоподавление остаётся. Гарнитура может дополнительно обрабатывать звук. RNNoise уменьшает окружающий шум, но чужую речь тоже может пропускать. В 1.2.1 срез около 5 кГц включается вместе с «Изоляцией голоса»; отдельного переключателя для него нет.

Для перевода откройте меню ⋮ в чате, затем «Перевод на экране» → «Переводить входящие сообщения». Переводятся видимые входящие текстовые сообщения и подписи, исходящие сообщения и оригиналы сохраняются. Начальный язык соответствует языку приложения; его можно поменять или вернуть оригинал. Сначала скачиваются модели, около 30 МБ на язык, по умолчанию через Wi-Fi. После этого перевод работает без сети, текст переписки сервису перевода не отправляется.

Настройки фона и обновлений находятся в Настройки → Danygramm. Разрешите уведомления и работу без ограничений батареи. APK скачивается по нажатию; перед системной установкой приложение проверяет размер, SHA-256, пакет, версию и сертификат.

Иконкой оставил бумажный самолётик Telegram, добавив две маленькие красные звезды на крыльях. В строке состояния Android показывает его монохромный силуэт.
