# Danygramm для Android

Danygramm основан на официальном исходном коде [Telegram для Android](https://github.com/DrKLO/Telegram).
Единственная добавленная пользовательская функция — **изоляция голоса на микрофоне в личных голосовых и видеозвонках**.

Это неофициальная сборка, не являющаяся продуктом команды Telegram.

Основа — **Telegram Android 13.0.2 (7175)**,
commit [`f32ffeec763f0bdbf4bec25b52d654f77bff733d`](https://github.com/DrKLO/Telegram/tree/f32ffeec763f0bdbf4bec25b52d654f77bff733d).

У сборки собственные название, иконка и сборочная конфигурация.
Часть интеграций и функций отключена или не настроена — см. [ограничения сборки](README_MICCONTROL_RU.md#ограничения-первого-варианта).

## Как включить изоляцию голоса

1. Во время личного звонка нажмите **«Микрофон»** внизу справа, над кнопками управления.
2. В открывшейся нижней панели выберите **«Изоляция голоса»**.

Режим **«Стандартный»** оставляет штатную обработку микрофона Telegram и не выключает микрофон.
Выбор применяется сразу и сохраняется для следующих личных звонков.

## Скачать и собрать

[Скачать Danygramm dev4](https://github.com/DV-Design/MicControl-Telegram/releases/tag/danygramm-dev4).
Репозиторий приватный: для скачивания нужно войти в GitHub под аккаунтом с доступом.

[Подробная инструкция по установке и сборке](README_MICCONTROL_RU.md).
Для собственной сборки нужны свои Telegram API credentials и ключ подписи.
Исходные требования Telegram к API, названию и сборке приведены в [README upstream](https://github.com/DrKLO/Telegram/blob/f32ffeec763f0bdbf4bec25b52d654f77bff733d/README.md).
