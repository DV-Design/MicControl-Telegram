# Danygramm для Android

Danygramm основан на официальном исходном коде [Telegram для Android](https://github.com/DrKLO/Telegram). Это неофициальная сборка со следующими изменениями:

- Три режима микрофона в личных звонках: **изоляция голоса**, **шумоподавление**, **без эффектов**. Изоляция усилена относительно dev4.
- **Перевод на экране**: полученные сообщения и подписи переводятся на устройстве, исходящий текст и оригиналы сохраняются.
- Фоновое соединение для сообщений и звонков, настройки разрешений и проверка подписанных обновлений из этого репозитория.
- Название Danygramm и бумажный самолётик с красными звёздами на крыльях; соответствующий монохромный значок в строке состояния.

Основа — **Telegram Android 13.0.2 (7175)**, commit [`f32ffeec763f0bdbf4bec25b52d654f77bff733d`](https://github.com/DrKLO/Telegram/tree/f32ffeec763f0bdbf4bec25b52d654f77bff733d).

Предварительный релиз для проверки звука на телефоне: RNNoise сильнее подавляет шумовые частотные полосы. Тихие начала слов могут ослабляться; при необходимости выберите обычное «Шумоподавление». UI-тесты этой версии не запускались по просьбе пользователя. Автоматическое обновление остаётся на стабильной 1.0.

Репозиторий публичный, для скачивания вход в GitHub не нужен. Пакет и сертификат сохранены: APK устанавливается поверх прежнего MicControl/Danygramm без удаления приложения.

## Как пользоваться

**Микрофон:** в личном аудио- или видеозвонке нажмите «Микрофон» внизу справа и выберите режим. Панель появляется по нажатию. В режиме «Без эффектов» отключены подавление шума, изоляция и автоматическое усиление; защита от эха сохраняется. Гарнитура может дополнительно обрабатывать звук.

**Перевод:** меню ⋮ в чате → «Перевод на экране» → «Переводить входящие сообщения». Язык по умолчанию соответствует языку приложения. Можно выбрать другой язык и вернуть оригинал. Сначала скачиваются языковые модели (около 30 МБ на язык, по умолчанию через Wi-Fi), затем перевод работает без сети. Текст переписки не отправляется сервису перевода.

**Фон и обновления:** Настройки → Danygramm. Для своевременных сообщений и звонков нужны разрешённые уведомления и работа без ограничений батареи. Проверка обновлений не устанавливает APK автоматически: перед системной установкой проверяются размер, SHA-256, пакет, версия и сертификат.
