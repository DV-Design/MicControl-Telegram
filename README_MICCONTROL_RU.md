# Danygramm для Android

Неофициальная сборка на основе официальных исходников Telegram Android 13.0.2 (7175), upstream commit `f32ffeec763f0bdbf4bec25b52d654f77bff733d`.

## Установка

[Скачать Danygramm 1.0](https://github.com/DV-Design/MicControl-Telegram/releases/download/danygramm-1.0/Danygramm-arm64.apk) · [Релиз и контрольная сумма](https://github.com/DV-Design/MicControl-Telegram/releases/tag/danygramm-1.0).

Версия `13.0.2-danygramm-1.0`, code `71799`, Android 6+ (min 23, target 36), arm64. Это вариант **AfatStandalone**, без разрешённой отладки и автоматического включения debug-логов. Минификация отключена. Пакет `org.miccontrol.messenger.web` и сертификат SHA-256 `59e104c1d8b66e20c47119aed387993df655475cdd3153fb21bfb3752d85debe` сохранены для обновления предыдущих установок без удаления данных.

Репозиторий публичный. APK можно скачать без авторизации в GitHub. Android может запросить разрешение на установку из выбранного источника.

```bash
adb install -r artifacts/Danygramm-arm64.apk
```

Не удаляйте приложение перед установкой обновления: удаление стирает его локальные данные. Смена подписи не используется как способ исправления установки.

## Микрофон

Во время личного аудио- или видеозвонка нажмите **«Микрофон» внизу справа**, над основными кнопками. Нижняя панель открывается только по нажатию; текущая строка отмечена радиопереключателем и контрастным фоном.

| Режим | Обработка |
|---|---|
| Изоляция голоса | WebRTC NS и RNNoise с усиленным подавлением шумовых частотных полос |
| Шумоподавление | WebRTC NS и обычная обработка голоса без RNNoise |
| Без эффектов | Без NS, RNNoise, автоматического усиления и дополнительного фильтра высоких частот |

Эхоподавление остаётся под управлением движка звонка для защиты от обратной связи. Аппаратная обработка гарнитуры может сохраняться независимо от приложения. Настройка применяется сразу и запоминается. Старый включённый режим изоляции переносится в «Изоляцию голоса», прежний «Стандартный» — в «Шумоподавление».

В RNNoise коэффициент спектрального подавления увеличен с 1,00 до 1,30. Это не уменьшение общей громкости микрофона: частотные полосы речи с коэффициентом около единицы сохраняются. На одинаковом синтетическом шуме нативный тест измерил отношение остаточной энергии 0,718265 к предыдущей обработке, то есть снижение на 28,2%. Это результат конкретного образца, а не гарантия одинакового процента для любого шума.

RNNoise в этой версии не распознаёт владельца голоса и не отделяет надёжно его речь от других говорящих. Выделение только голоса владельца — отдельная следующая задача (`miccontrol-adn`).

Групповые звонки и конференции сохраняют штатную обработку Telegram. До ответа на входящий звонок, в группах, конференциях и PiP кнопка режима скрыта. Выбор не переключает системные режимы AirPods или OriginOS.

## Перевод переписки на экране

В меню ⋮ чата откройте **«Перевод на экране»** и включите перевод входящих сообщений. Для каждого чата можно выбрать целевой язык; начальный язык соответствует языку приложения. Панель над перепиской показывает состояние и открывает управление переводом. Действие «Показать оригиналы сообщений» возвращает исходный текст.

Переводятся видимые входящие текстовые сообщения и подписи к фото, видео и файлам. Оригинальные TL-сообщения и их entities не меняются, исходящие сообщения автоматически не переводятся. Опросы, статьи, распознавание голоса и элементы интерфейса остаются в прежнем виде.

Используются [Google ML Kit Translation](https://developers.google.com/ml-kit/language/translation/android) и уже имеющееся определение языка. Модели скачиваются по мере необходимости (примерно 30 МБ на язык); по умолчанию требуется Wi-Fi. Можно явно разрешить мобильную сеть. После скачивания перевод выполняется локально и доступен без интернета. Тексты переписки не передаются сервису перевода. Premium и отдельный API-ключ переводчика не требуются.

При ошибке, неизвестном языке или недоступной модели остаётся оригинал. После ошибки повтор запускается явно из меню, чтобы перерисовка чата не вызывала повторные загрузки. Доступны выбор языка и удаление скачанных моделей. Одновременно допускается до четырёх моделей неанглийских языков; при достижении лимита сначала удалите ненужные модели. Закрытие чата и выключение перевода отбрасывают устаревшие результаты. SDK не предоставляет отмену уже начатого скачивания модели: остановка перевода отменяет применение результата, а загрузка SDK может завершиться в фоне.

## Работа в фоне и обновления

Откройте **Настройки → Danygramm**:

- Фоновые уведомления: тихая постоянная служба поддерживает собственное соединение Telegram при наличии авторизованного аккаунта.
- Системные уведомления, полноэкранные входящие звонки и настройки батареи: переходы к соответствующим экранам Android.
- Проверка обновлений: чтение последнего стабильного релиза из этого GitHub-репозитория.

Фоновое соединение использует существующий механизм Telegram. Собственный Firebase-проект не требуется для выбранного способа доставки. Не настроенный FCM не выдаётся за работающий push-провайдер. Служба использует тип Android `specialUse` с указанным назначением; тип `dataSync` с временным лимитом для постоянного соединения не используется. Служба не включает микрофон или камеру.

Разрешите уведомления, работу без ограничений батареи и автозапуск, если OriginOS предлагает отдельную настройку. Принудительная остановка приложения в системных настройках блокирует доставку до следующего открытия; это ограничение Android. Работа реальных входящих сообщений/звонков после длительного сна на vivo требует проверки на устройстве с авторизованным аккаунтом.

Обновления проверяются автоматически не чаще раза в сутки и вручную из настроек. APK скачивается только после нажатия. Перед установкой проверяются размер, SHA-256, пакет, возрастающий versionCode и сертификат. Другая подпись, подмена файла и откат версии блокируются. Окончательная установка выполняется системным установщиком Android.

## Иконка

Бумажный самолётик сохраняет форму и пропорции Telegram; на крыльях добавлены две маленькие красные звёзды. Launcher и крупная иконка фонового уведомления используют цветной вариант. Android окрашивает маленькие значки строки состояния в один цвет: там используется тот же силуэт самолётика.

## Сборка

Проверенная конфигурация: JDK 21, Android SDK platforms 35/36, Build Tools 36.0.0, NDK 27.2.12479018, CMake 3.22.1, Gradle wrapper 8.13. Пример SDK/API настроек: [local.properties.example](local.properties.example).

Для своей API application получите `api_id` и `api_hash` на [my.telegram.org/apps](https://my.telegram.org/apps). Укажите `TELEGRAM_API_ID` и `TELEGRAM_API_HASH` в исключённом из Git `local.properties` либо в переменных окружения. Не добавляйте их в исходники. Sample API запрещён в standalone-сборке.

Для обновления существующего Danygramm нужен существующий `.local/miccontrol-debug.keystore`. Название файла историческое: тот же ключ подписывает сборку без debug. Скрипт не создаёт замену автоматически и проверяет fingerprint до и после сборки. Ключ не входит в публичный репозиторий.

```bash
git submodule update --init --recursive --depth=1
./scripts/build-apk.sh
```

Результаты:

- `artifacts/Danygramm-arm64.apk`
- `artifacts/Danygramm-arm64.apk.sha256`
- `artifacts/danygramm-update.json`

Gradle APK: `TMessagesProj_AppStandalone/build/outputs/apk/afat/standalone/app.apk`. Скрипт ограничивает ABI до arm64, Gradle до двух workers и heap 4 GB. Для отладочной локальной сборки предусмотрен `--debug`; это отдельный артефакт.

В GitHub Actions уже настроены `TELEGRAM_API_ID`, `TELEGRAM_API_HASH`, `MICCONTROL_DEBUG_KEYSTORE_B64`. Workflow восстанавливает ключ только на время сборки, проверяет подпись и публикует только APK, SHA-256 и metadata. Для нового форка с другой подписью нужно изменить собственную сборочную конфигурацию и pin сертификата обновлений.

## Проверки

[Android runtime tests](tests/miccontrol/ANDROID_RUNTIME_TESTS.md) содержат точный объём проверки каждой версии. Проверка сборки и подписи не заменяет вход в аккаунт, получение сообщений или настоящий звонок. Личный вход в dev3 подтверждён пользователем 18 октября; повторные запросы кода для текущих проверок не используются.

```bash
python3 tests/miccontrol/run_native_tests.py --sanitize
python3 tests/miccontrol/run_native_tests.py --sanitize --speech-wav path/to/48000hz-mono-pcm16.wav
```

ASan/UBSan покрывают RNNoise, resampling, mono/stereo 8/16/32/48 кГц, точный bypass, тишину, независимость каналов, повторные переключения и освобождение памяти. Android-проверки используют реальный APK и его нативную библиотеку.

## Если код входа не приходит

Для личного аккаунта выключите **Test Backend / Тестовый сервер** на экране номера: эта отдельная среда не связана с обычным Telegram. Выбор сохраняется при обновлении приложения. Экран кода через Telegram означает, что способ доставки выбрал сервер; приложение не может гарантированно заменить его на SMS. [Авторизация Telegram](https://core.telegram.org/api/auth).

## Особенности и ограничения

- Google Maps остаётся без собственной конфигурации.
- Google Sign-in, passkeys, официальные SMS Retriever подписи и Google Play Billing отключены; доступен вход по номеру с ручным вводом кода.
- Официальный updater Telegram отключён; Danygramm использует свой источник GitHub Releases.
- В этом релизе собрана только arm64-архитектура. Публикация в магазинах не выполняется.
- Качество звонка, маршрутизация Bluetooth и ограничения батареи OriginOS проверяются на реальном vivo/AirPods с собеседником.
