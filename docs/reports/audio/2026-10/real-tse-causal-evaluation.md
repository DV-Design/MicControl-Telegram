## Фактическая конфигурация

- `TSE_BSRNN_SPK`; в YAML явно задано `separator.causal: true`, перекрывающее исходный default `False`.
- Моно 16 кГц; окно 512, шаг 128; `feature_dim=128`, шесть повторов, один выход. Исходник выбирает cLN и однонаправленную временную LSTM для causal-режима. Двунаправленная коммуникация по частотным полосам относится к одному временному кадру.
- Включён только `spkemb`, объединение `multiply`. `listen`, `usef`, `tfmap`, `context` выключены.
- Глобальный `ECAPA_TDNN_GLOB_c512`: embedding192, вход80 mel, pooling `ASTP`.
- Fbank: Hamming, 25/10 мс, `dither=1.0` из YAML, mean normalization без variance normalization. Официальный loader не обнуляет dither; вариант0.0 следует отмечать как отдельное изменение.
- Training-local `pretrained` указывает на `./wespeaker_models/voxceleb_ECAPA512/avg_model.pt`. Официальный local loader заменяет его на `None`, затем строго загружает полный checkpoint. Полноту encoder-тензоров подтверждает последующая безопасная загрузка.
- В отключённом разделе context есть лишний ключ `fusion"`; активный `spkemb.fusion` корректен. Исходный config сохранён без исправлений.

Для измерения утечки речи требуется отключить официальный `output_norm`, который по умолчанию растягивает пик каждого выхода до0.9. README рекомендует Torch/torchaudio2.7.1; устанавливать весь старый training requirements для этой проверки не требуется.

## Лицензия и ограничения

Заголовки исходников модели, frontend и BSRNN содержат `SPDX-License-Identifier: Apache-2.0`. В зафиксированном репозитории не найден отдельный LICENSE, а среди12 записей архива нет LICENSE/NOTICE. Явное разрешение на распространение самих весов не установлено; его нельзя выводить только из лицензии кода.

Checkpoint содержит также optimizer/scheduler/scaler, поэтому его размер нельзя считать размером inference-модели. Безопасная загрузка `torch.load(weights_only=True, mmap=True)` на CPU обнаружила `models[0]`: 948 tensor keys (890 float32, 58 int64), 31 272 386 сериализованных элементов, все конечные; unsafe globals не обнаружены. Изолированные версии: Torch 2.14.1 и torchaudio 2.11.0. Доказательство: `artifacts/qa/target-voice/real-tse-causal/checkpoint-inventory.json`.

Полное соответствие модели checkpoint, качество, ONNX-экспорт, итоговый размер inference-графа, скорость Android и физический телефон этим этапом не проверены. Конфигурация causal не заменяет проверку потокового исполнения и качества при отсутствующем владельце.
