# Окружающий шум: спектральное усиление RNNoise

20 октября 2026, задача `miccontrol-czi`. Спектральный вариант **1.6 принят
для пробной сборки**, с оговоркой о тихом начале речи. Это не подтверждение
универсальной разборчивости. Физический телефон, реальный звонок и UI не
проверялись; UI-тесты пользователь отключил.

## Изменение и границы

У [VoiceIsolationDenoiser](../../../../TMessagesProj/jni/voip/miccontrol/VoiceIsolationDenoiser.cpp)
параметр по умолчанию изменён с `0.30` на `0.60`, то есть показатель степени
спектрального коэффициента RNNoise — с `1.3` на `1.6`. Соответственно поднят
верхний предел в [denoise.c](../../../../TMessagesProj/jni/voip/rnnoise/src/denoise.c).
Это усиливает уже выбранное моделью ослабление отдельных частотных полос;
общий регулятор громкости не добавлен. Новых буферов, операций выделения памяти
или задержки в обработке нет.

Явный C API с показателем `1.3` сохранил **побитно идентичные выходы на всех
девяти тех же входах**. Обычная точка входа `rnnoise_process_frame` для групп
по-прежнему использует `1.0`. Три режима микрофона, Java/UI, APM и обработка эха
не изменялись. Изоляция голоса продолжает быть шумоподавлением и не отделяет
владельца от других говорящих.

## Метод и результаты

[Репродуктор](../../../../tests/miccontrol/run_ambient_noise_tests.py) использует
полные независимые фразы LibriSpeech: `6930-75918-0007`, `1320-122617-0012`,
`5639-40744-0002`. Для каждого голоса — чистая запись и смесь соответственно
с дождём, пылесосом или клавиатурой; дополнительно три случая только с шумом.
Каждая фраза повторяется дважды с секундными паузами. Вход — mono 48 кГц
FloatS16, блоки 480, речь RMS `0.06`, шум номинально на 10 дБ ниже речи.
Нормализации выходов нет. Для сравнения с чистой речью используется фиксированная
задержка 480 отсчётов. Gain оценивается методом наименьших квадратов; SI-SDR
нечувствителен к общему масштабу и приводится вместе с gain.

| Запись окружающего шума | Дополнительное снижение, только шум | В паузах смеси |
| --- | ---: | ---: |
| Дождь | 1.022 дБ | 1.503 дБ |
| Пылесос | 3.832 дБ | 7.538 дБ |
| Клавиатура | 3.053 дБ | 6.127 дБ |

Активная чистая речь сохранила 99.845–99.973% прежнего reference gain; в смесях
— 97.302–99.583%. Изменение SI-SDR чистой речи: `+0.018 / −0.012 / −0.002` дБ;
в смесях: `−0.332 / −0.020 / +0.147` дБ.

Есть локальная плата за усиление: у чистого B первые 40 мс имеют gain ratio
`0.9362`, у чистого C первые 20 мс — `0.9019` (около −0.90 дБ). Некоторые очень
слабые начала, уже сильно подавленные исходным RNNoise, ослабляются ещё заметнее.
Поэтому общий RMS не используется как доказательство сохранения всех согласных.
ASR, MOS и прослушивание для оценки разборчивости этим этапом не выполнялись.
При нежелательном ослаблении доступен прежний режим «Шумоподавление».

## Отклонённый вариант и проверки

Перед спектральным вариантом один раз проверен мягкий VAD-expander: порог
`0.005`, удержание 300 мс, максимум 6 дБ, открытие 1 мс. Он почти не помог
окружающим звукам: дождь −0.263 дБ, клавиатура −0.0004 дБ, пылесос без изменений,
при этом reference gain начала речи в дожде за 200 мс снизился на 6.4%.
Вариант снят полностью; повторного подбора VAD-порогов не было.

Финальная нативная проверка **ASan + UBSan PASS**: 8/16/32/48 кГц, mono/stereo,
точный bypass, конечные значения, тишина, независимость каналов, Reset и
400 переключений. Учёт выделенных RNNoise GRU-буферов подтвердил освобождение
после каждого сценария. В steady capture новых RNNoise allocation не обнаружено.
LeakSanitizer на этом macOS не поддерживается (`detect_leaks=0`); это не полный
LSan-аудит heap. На отдельной неизменённой TTS-фразе default/1.3 energy ratio
`0.986620`, cosine `0.999814`; синтетический шум — energy ratio `0.746408`.

Доказательства под `artifacts/qa/ambient-noise/`: `before/result.json`,
`after/result.json` и `rejected-pause-expander.patch` (отклонённый VAD),
`spectral-1.6/result.json`, `spectral-1.6/baseline-compatibility.json`,
`final-spectral-1.6-native-asan.log`. `final-verification.json` содержит SHA-256
трёх DSP-файлов, трёх файлов тестов, всех девяти входов/выходов и аудиоисточников.

Повторный прогон матрицы требует существующих закреплённых LibriSpeech FLAC,
NumPy 2.5.4, soundfile 0.14.0, Torch 2.14.1 и torchaudio 2.11.0; Torch используется
только для sinc-resampling тестовых файлов, target-speaker inference нет:

```sh
.local/tse-baseline-venv/bin/python tests/miccontrol/run_ambient_noise_tests.py \
  --download-fixtures --output-dir artifacts/qa/ambient-noise/reproduced
ASAN_OPTIONS=detect_leaks=0:halt_on_error=1 UBSAN_OPTIONS=halt_on_error=1 \
  python3 tests/miccontrol/run_native_tests.py --sanitize \
  --speech-wav artifacts/qa/1.0-clean-speech.wav
```
